# results/

Empty by design.

This directory is populated only by `python run.py results`, which reads run
artifacts under `runs/` and writes `SUMMARY.md` and `results.json`. Every value
it writes is either measured on this machine, with a path to the artifact it
came from, or the literal string `not run`.

Nothing here is carried over from a previous run. The v1 numbers — stability
r = 0.5268, gene-disjoint pathogenicity AUROC = 0.669, and the rest — were
produced by a different architecture on differently-constructed splits, and
reporting them beside v2 code would attribute them to a model that never
produced them. They remain on the `version-1` branch, with their configs.

The `images/` figures from the predecessor repository are not here either. They
were generated by a demo path that synthesised plots from hardcoded target
metrics rather than from predictions, so they are not evidence of anything.

To populate this directory:

    python run.py all

Until then, every claim about model performance in this repository should read
"not yet measured", because it has not been.
